  • Fields.FieldAxioms.mul_left_cancel

Within any type satisfying these field axioms, one has additive and multiplicative cancellation laws.

Proof ▶

For additive cancellation, if \(a+b=a+c\), add \(-a\) to both sides and simplify using the field axioms to obtain \(b=c\). For multiplicative cancellation, if \(a eq 0\) and \(ab=ac\), multiply both sides by \(a^{-1}\) and use associativity together with \(a^{-1}a=1\) to conclude \(b=c\).

Lean declarations

  • Fields.OrderedField.inv_lt_inv_of_pos

In an ordered field, negatives of positive elements are negative, squares of nonzero elements are positive, and inversion reverses order on positive elements.

Proof ▶

If \(a{\gt}0\), then \((-a)+a=0\) forces \(-a{\lt}0\), since \(-a\ge 0\) would make \(0=(-a)+a{\gt}0\). For a nonzero \(a\), either \(a{\gt}0\) or \(-a{\gt}0\); in both cases \(a^2\) is a product of positive numbers, so \(a^2{\gt}0\). Finally, if \(0{\lt}a{\lt}b\), then multiplying by the positive number \((ab)^{-1}\) preserves order and gives \(1/b{\lt}1/a\).
